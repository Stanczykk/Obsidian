# Move the Changes to the Stage
When youre done with your changes you can save it then go to the next step 

1. Save Working Directory 
2. Stage (Middleground)
3. Local Repository

Then you commit permanently saving it to your local repository 

> A **Repository** is a place where all the versions of your files and their complete change history are stored.
