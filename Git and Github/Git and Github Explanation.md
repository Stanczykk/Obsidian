# Git = Your Time Machine

Git is software installed on your computer.

It keeps track of every change you make.

Instead of saving files like

```
notes.docx
notes-final.docx
notes-final-final.docx
notes-final-reallyfinal.docx
```

Git remembers every version automatically.

You can

- save snapshots
- undo mistakes
- compare versions
- create experimental branches
- merge work together

Git works **without the internet**.

# GitHub = Cloud Storage for Git

GitHub is a website.

It stores Git repositories online.

Benefits:

- backup
- collaborate with others
- contribute to open source
- portfolio for employers
- access projects anywhere

Think of it like this

```
Git
↓
Version Control

GitHub
↓
Cloud Storage + Collaboration
```

Git does the work.
