# The Big Picture

Imagine this workflow.

```
You edit code
      ↓
Git notices changes
      ↓
You stage changes
      ↓
You commit (save a snapshot)
      ↓
You push
      ↓
GitHub stores it online
```

That's literally 90% of daily Git usage.

# ***IMPORTANT VOCABULARY***
**Repository (Repo)**
A project tracked by Git.
 
 Example:
```
Todo App
Portfolio
My Obsidian Vault
```
Each is its own repository.

# Commit 
A snapshot.

Imagine pressing Save in a video game.
```
Commit #1
Website Home Page

Commit #2
Added Login

Commit #3
Fixed Login Bug
```

You can always go back.

# Stage
Git doesn't automatically save everything.
Instead you choose what to include.
Think of it like placing files inside a shipping box.
Only what's inside gets shipped.

# Push
Uploads commits to GitHub.
